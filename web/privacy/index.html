المعلومات التي نجمعها

قد نجمع الاسم، البريد الإلكتروني، رقم الهاتف، معرّف المستخدم، بيانات الملف الشخصي، العنوان، بيانات الطلبات والمشتريات، والموقع التقريبي أو الدقيق عند منح الإذن. وقد نجمع الصور أو الوصف أو الرسائل التي يرسلها المستخدم طوعًا عبر المزاد أو الدعم أو ميزات التطبيق الأخرى.

كيفية استخدام المعلومات

نستخدم البيانات لتشغيل التطبيق، إدارة الحسابات، معالجة الطلبات، التوصيل، خدمة العملاء، المكافآت، تحسين الأداء، وإرسال تنبيهات الخدمة.

الموقع الجغرافي

عند منح إذن الموقع، قد نستخدمه لعرض الأماكن القريبة، تحديد نطاق التوصيل وتنفيذ الطلب. يمكن إيقاف الإذن من إعدادات الجهاز.

الحجوزات والاستشارات الصحية

عند حجز موعد مع طبيب أو إرسال استشارة، نجمع تفاصيل الموعد ونص الرسالة الذي يكتبه المستخدم، وقد تتضمن الرسالة معلومات صحية يختار المستخدم تقديمها. تظهر هذه البيانات للطبيب أو العيادة المختارة ولإدارة بركة عند الحاجة للتشغيل والدعم. بركة منصة للحجز والتواصل وليست جهازًا طبيًا ولا تقدم تشخيصًا أو علاجًا ولا تستبدل الرعاية الطبية المهنية.

مشاركة البيانات

قد نشارك الحد الأدنى اللازم مع المطاعم والمتاجر ومقدمي التوصيل والأطباء أو العيادات التي يختارها المستخدم، ومزودي البنية التقنية مثل Firebase وCloudflare لتشغيل الخدمة. وقد تصل خدمات الخرائط إلى بيانات تقنية لازمة لعرض الخريطة. لا تبيع بركة البيانات الشخصية.

الحماية والاحتفاظ

تُنقل البيانات عبر اتصالات مشفرة، ونتخذ إجراءات تقنية وتنظيمية معقولة لحمايتها. نحتفظ بها للمدة اللازمة لتشغيل الخدمة والمحاسبة وتسوية النزاعات والامتثال للالتزامات القانونية، ثم نحذفها أو نجعلها غير مرتبطة بالمستخدم عندما تنتفي الحاجة.

حقوق المستخدم والحذف

يمكنك طلب الاطلاع على بياناتك أو تصحيحها أو حذف حسابك. يشمل الحذف ملف الحساب والمفضلة والرموز والإحداثيات والبيانات الشخصية المرتبطة التي لا يلزم الاحتفاظ بها، وقد نحتفظ بسجلات الطلبات والمعاملات الضرورية للالتزامات القانونية أو تسوية النزاعات. راجع صفحة حذف الحساب.
